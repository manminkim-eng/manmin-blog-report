# MANMIN 엔지니어링 웹(WAP) 방문 리포트 — 작업지시서

기준일 2026-08-09 · VER-1.0 · 건축사 김만민(#20072)

## 1. 목적과 범위

`manminkim-eng.github.io` 전 저장소의 **월간 방문 지표**를 매달 같은 기준으로 색인한다.
지표를 많이 모으는 것이 아니라 **월별 비교가 가능한 상태**를 유지하는 것이 목적이다.

| 채널 | 대상 |
|---|---|
| 엔지니어링 플랫폼 | `/KIMMANMIN` |
| 개별 WAP | `/u-value-app-`, `/Fire-Protection-Systems` 등 저장소별 |
| 종합관리 허브 | `/manmin-hub` |
| 리포트 사이트 | `/manmin-blog-report`, `/manmin-blog-report/youtube` |

## 2. 도구별 역할 — 섞어 쓰지 않는다

| 층 | 도구 | 역할 | 보존 기간 |
|---|---|---|---|
| **정본** | GoatCounter | 월별 방문자 — 리포트의 유일한 근거 | 무제한 |
| 보조 | Cloudflare Web Analytics | Core Web Vitals(LCP·INP·CLS) | **최대 30일** |
| 외부 | 네이버 통계 · YouTube Studio | 각 플랫폼 고유 지표 | 플랫폼 정책 |

**방문자 수는 GoatCounter만 인용한다.** Cloudflare는 조회 기간이 30일이라 월별 비교가 불가능하며, 두 도구의 숫자를 섞어 인용하면 수치가 어긋나 신뢰를 잃는다.

## 3. 계측 스니펫 — 정본 1개, 절대경로 참조

모든 사이트가 `manminkim-eng.github.io` 같은 오리진을 공유한다. 저장소마다 파일을 복사하지 않고 정본 하나를 참조한다.

```html
<script defer src="/manmin-blog-report/web/assets/manmin-analytics.js"></script>
```

- 위치: HTML `<head>` 안 (관례상 `<head>` 바로 다음 줄)
- 맨 앞 `/` 필수 — 절대경로이므로 하위 폴더든 최상위든 **동일한 한 줄**
- 정본 파일: `manmin-blog-report/web/assets/manmin-analytics.js`

### 내장 안전장치
| 기능 | 동작 |
|---|---|
| 중복 주입 방지 | 이미 GoatCounter·Cloudflare 스크립트가 있으면 그것만 건너뜀 |
| 로컬 제외 | `file://` · `localhost` · 사내망(192.168.x)에서 자동 비활성 |
| 본인 제외 | 콘솔에서 `localStorage.setItem("manmin-skip-analytics","1")` |

### 금지사항
`manmin-blog-report` 저장소를 **삭제·개명하면 안 된다.** 전 WAP의 계측이 함께 끊긴다.

## 5. 월간 갱신 절차

### 자동 (권장)
예약 작업 `manmin-web-monthly-index` 가 **매월 1일 08:20** 실행된다.
(블로그 08:00 · 유튜브 08:10 과 동일 계열)

### 수동
```bat
cd /d "Z:\MIN-A\01.만민자료\02.설계자료\11.개발자료\60.개발자료[블로그우]\90.분석자료\manmin-blog-report\web"
python build_web.py --month 2026-09 --period "2026.09 월간"
```
- 토큰은 `web/token.txt` 에서 자동 로드된다(인자 불필요)
- 원본 JSON은 `web/<YYYY-MM>/data/` 에 보관 → 이후 `--offline` 으로 재생성 가능

### 푸시
Z:는 NAS(`//192.168.0.36/min-a`)라 샌드박스에서 git이 동작하지 않는다.
**GitHub Desktop → Commit → Push origin** 으로 올린다.

## 6. 알아둘 함정

| 함정 | 증상 | 대응 |
|---|---|---|
| **Chrome 자동번역** | 대시보드에서 `/KIMMANMIN`이 `/김만민`으로, `blog.naver.com`이 `블로그.네이버.com`으로 보임 | goatcounter.com 자동번역 끄기. 판단은 API 원본값으로 |
| **레이트 리밋** | API 병렬 호출 시 절반이 `rate limited`로 빈 데이터 | 순차 호출 + 0.4초 간격. `build_web.py`에 재시도 내장됨 |
| **GitHub Pages 캐시** | 커밋 후에도 옛 파일이 보임 | `max-age=600` — 최대 10분 대기 |
| **경로 파편화** | 같은 페이지가 `/x`, `/x/index.html`, `/x?v=2`로 갈라짐 | `build_web.py`가 자동 병합(정규화) |
| **구 저장소 경로** | `/manmin-blog/...` (개명 전) | 현행 채널로 병합 처리됨 |
| **편집기 좌표 이동** | GitHub 웹편집에 "저장되지 않은 변경사항" 배너가 뜨면 화면이 58px 내려감 | 배너를 닫고 진행 |

## 7. 보안

- API 토큰은 **`통계 자료 읽기` 권한만** 부여한다. 쓰기 권한이 붙은 토큰은 즉시 폐기·재발급한다.
- `token.txt` 는 `web/.gitignore` 에 등록되어 있다. **절대 커밋하지 않는다.**
- 토큰 유출이 의심되면 GoatCounter → 설정 → API 에서 삭제하면 즉시 무효가 된다.
