# MANMIN 계측 스니펫 배포 안내 (1단계 · 주요 WAP 10종)

기준일 2026-08-09 · 정본 `manmin-blog-report/web/assets/manmin-analytics.js`

## 1. 왜 필요한가

현재 계측이 파편화되어 있습니다. 등재 WAP 36종 중 방문자가 잡히는 곳은 4곳뿐입니다.

| 사이트 | Cloudflare | GoatCounter |
|---|---|---|
| manmin-hub | O | X |
| KIMMANMIN | X | O |
| manmin-blog-report | X | O |
| manmin-blog-report/youtube | X | O |
| **개별 WAP 전체** | **X** | **X** |

## 2. 도구별 역할 분담

| 항목 | GoatCounter | Cloudflare Web Analytics |
|---|---|---|
| 역할 | **월별 정본** | 성능 보조 |
| 보존 기간 | 무제한 누적 | **최대 30일** |
| Core Web Vitals | 없음 | LCP·INP·CLS |
| 월간 리포트 근거 | O | X (30일 상한) |

Cloudflare 단독으로는 월별 비교가 불가능하므로 GoatCounter를 정본으로 둡니다.

## 3. 적용 방법 (저장소당 30초) — 파일 복사 불필요

모든 저장소가 `manminkim-eng.github.io` **같은 오리진**을 공유합니다. 따라서 스크립트를 저장소마다 복사할 필요 없이, 정본 한 곳을 절대경로로 참조하면 됩니다.

각 HTML 의 `</head>` 직전에 **이 한 줄만** 넣으십시오.

```html
<script defer src="/manmin-blog-report/web/assets/manmin-analytics.js"></script>
```

맨 앞 `/` 가 중요합니다. 절대경로이므로 하위 폴더 HTML이든 최상위든 **동일한 한 줄**을 씁니다. 상대경로 계산이 필요 없습니다.

### 이 방식의 이점

| 항목 | 저장소마다 복사 | 절대경로 참조(채택) |
|---|---|---|
| 저장소당 작업 | 파일 복사 + 경로 조정 | 한 줄 붙여넣기 |
| 엔드포인트 변경 시 | 36곳 전부 수정 | **정본 1곳만 수정** |
| 버전 불일치 위험 | 있음 | 없음 |
| 브라우저 캐시 | 저장소마다 별도 | 전 사이트 공유 (1회 다운로드) |

### 주의
정본 파일이 있는 `manmin-blog-report` 저장소는 삭제·개명하면 안 됩니다. 전 WAP의 계측이 함께 끊깁니다.

커밋·푸시 후 GitHub Pages 재배포를 기다렸다가 실제 접속해 계측을 확인하십시오.

### 중복 걱정 없음
스크립트에 중복 주입 방지가 들어 있습니다. KIMMANMIN처럼 이미 GoatCounter 인라인 스니펫이 있는 페이지에 넣어도 이중 집계되지 않고, 없는 쪽(Cloudflare)만 추가됩니다.

### 개발 중 통계 오염 방지
`file://`·`localhost`·사내망(192.168.x)에서는 자동 비활성입니다.
본인 브라우저를 통계에서 빼려면 콘솔에서 한 번 실행하십시오.

```js
localStorage.setItem("manmin-skip-analytics", "1")
```

## 6. 월간 리포트 생성

GoatCounter API 토큰이 필요합니다. GoatCounter 우측 상단 사용자 메뉴 → **API** → 읽기 권한 토큰 생성.

```bat
cd /d "Z:\MIN-A\01.만민자료\02.설계자료\11.개발자료\60.개발자료[블로그우]\90.분석자료\manmin-blog-report\web"
python build_web.py --month 2026-08 --period "2026.08 월간" --token <발급토큰>
```

원본 JSON은 `web/<YYYY-MM>/data/` 에 보관되며, 이후 `--offline` 으로 재생성할 수 있습니다.
토큰은 저장소에 커밋하지 마십시오 — `web/.gitignore` 에 `token.txt` 가 등록되어 있습니다.
